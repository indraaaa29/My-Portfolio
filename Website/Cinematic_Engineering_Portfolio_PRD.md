# Product Requirements Document (PRD)

## Project

**Cinematic Engineering Portfolio**

**Owner:** Indranil Paul

**Version:** 1.0

------------------------------------------------------------------------

# 1. Vision

Create a premium engineering portfolio where photography and cinematic
storytelling influence the visual language, while engineering remains
the primary focus.

> **An engineer who observes the world like a photographer and builds
> products with intention.**

# 2. Goals

-   Showcase engineering projects first.
-   Highlight AI, software engineering, and full-stack skills.
-   Create a memorable recruiter experience.
-   Demonstrate design thinking and storytelling.

# 3. Audience

-   Recruiters
-   Hiring managers
-   Startup founders
-   Engineers
-   Hackathon judges

# 4. Brand Identity

-   Cinematic
-   Premium
-   Minimal
-   Modern
-   Intentional

Photography is the style. Engineering is the story.

# 6. Design Principles

-   Motion with purpose
-   Large typography
-   Editorial spacing
-   Dark theme
-   Warm amber accents
-   Camera-inspired transitions
-   Content-first

# 7. Functional Requirements

-   Responsive
-   SEO
-   Accessibility
-   Smooth scrolling
-   Resume download
-   Contact form
-   GitHub & LinkedIn integration

# 8. Motion Language

-   Blur → Focus
-   Aperture transitions
-   Slow parallax
-   Fade reveals
-   Camera-inspired movement

# 9. Content Strategy

Engineering receives 85--90% of the attention. Photography supports the
visual identity only.

Every project should explain: - Problem - Thinking - Solution - Tech
Stack - Architecture - Impact - Lessons

# 10. Success Criteria

-   Lighthouse \>95
-   Fast loading
-   Memorable first impression
-   Strong engineering storytelling

# 11. Future Scope

-   AI assistant
-   Interactive engineering playground
-   CMS
-   Multilingual support

# Definition of Done

Visitors should leave thinking:

> This is an engineer with a distinctive perspective and the ability to
> build meaningful products.
